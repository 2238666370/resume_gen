# R8-A1 模板可视化编辑器（拖拽布局 + 字段绑定 + Schema 模型）

> 来源：`requirements.md` §4（R8 候选 A 拆分）\`R4-模板数据化.md\`
> 阶段：阶段四 | 难度：⭐⭐⭐⭐⭐ 高 | 依赖：R4 模板表（`template.schema` / `type=user`）、R8-A2 渲染引擎、R8-A3 模板市场

## 1. 定位

让普通用户**无需写前端代码**，通过可视化拖拽画布创建自定义简历模板（`template.type=user`），编辑器输出标准的 **Schema JSON**（区块清单 + 字段绑定 + 样式），交由 R8-A2 的统一渲染引擎消费。目标是承接 R4 已建的 `template` 表（当前仅 `type=official` 内置三套、`schema=NULL`），把「可视化绘制」从后置项落地为可交付能力。

## 2. 功能点

1. **画布编辑器**：组件面板 + 画布 + 属性面板三栏布局。
   - 从组件面板拖入区块组件：个人信息、头像、教育经历、工作/实习经历、项目经历、技能、自评、荣誉等（与 `ResumeDTO` 模块对应）。
   - 画布内拖拽排序、调整间距/边距/内边距。
   - 栅格布局：支持单列 / 双列 / 三列容器，区块可嵌套进列。
2. **字段绑定**：每个区块绑定简历数据路径（如 `skills[].name`、`experience[].description`、`personal.name`），配置显示名称、显示/隐藏、日期格式、空值占位。
3. **样式主题**：全局配色（`accentColor`，复用 `#RGB`/`#RRGGBB` 校验）、字体、字号、行高、对齐；区块级样式覆盖（颜色 / 边框 / 圆角 / 背景）。
4. **Schema 持久化**：将画布结果序列化为 `template.schema`（JSON），带 `schema_version`；保存前经 Schema 校验（JSON Schema 白名单）。
5. **实时预览**：画布内通过 R8-A2 渲染引擎在沙箱 iframe 中渲染当前简历数据（预览后导出样式一致）。
6. **草稿 / 发布**：草稿态（仅自己可见）与正式保存；编辑历史与版本记录（乐观锁 `version`）。

## 3. 数据模型

复用并扩展 R4 的 `template` 表（新增字段以**新增列**方式演进而非重建）：

```sql
ALTER TABLE template ADD COLUMN owner_user_id BIGINT DEFAULT NULL COMMENT '用户模板作者(隔离)' AFTER type;
ALTER TABLE template ADD COLUMN version INT NOT NULL DEFAULT 0 COMMENT '乐观锁版本' AFTER sort_order;
ALTER TABLE template ADD COLUMN schema_version INT NOT NULL DEFAULT 1 COMMENT 'Schema 版本' AFTER schema;
ALTER TABLE template ADD KEY idx_owner (owner_user_id);
```

**Schema 语义（关键）**——Schema JSON 结构示例：

```json
{
  "schemaVersion": 1,
  "theme": { "accentColor": "#3B82F6", "font": "sans", "fontSize": 14, "lineHeight": 1.6 },
  "sections": [
    {
      "id": "sec-header",
      "type": "container",
      "layout": "columns",
      "columns": [
        {
          "width": "70%",
          "blocks": [
            { "id": "b-name", "type": "text", "bind": "personal.name" },
            { "id": "b-title", "type": "text", "bind": "personal.title" },
            { "id": "b-summary", "type": "richtext", "bind": "personal.summary" }
          ]
        },
        {
          "width": "30%",
          "blocks": [{ "id": "b-avatar", "type": "image", "bind": "personal.avatar" }]
        }
      ]
    },
    {
      "id": "sec-exp",
      "type": "list",
      "bind": "experience",
      "itemTitle": "{{company}} · {{position}}",
      "itemBlocks": [
        { "id": "b-exp-range", "type": "date-range", "bind": "startDate/endDate" },
        { "id": "b-exp-desc", "type": "richtext", "bind": "description" }
      ]
    }
  ]
}
```

- `sections`：区块顺序即文档流顺序；`type=container/list/text/richtext/image/date-range` 等多态区块。
- `bind`：绑定 `ResumeDTO` 数据路径；校验必须是合法路径（白名单路径表，见 §7）。
- 官方三套模板后续可迁移为 Schema（`schema` 字段回填），渲染仍可回退硬编码组件（R8-A2 兼容）。

## 4. 接口（`/api/templates`，登录）

| 方法 | 路径 | 说明 | 鉴权 |
|------|------|------|------|
| POST | `/api/templates` | 创建自定义模板（`type=user`） | 登录 |
| PUT | `/api/templates/{id}` | 更新模板（含 schema，乐观锁） | 登录（作者） |
| GET | `/api/templates/{id}` | 模板详情（含 schema） | 登录（作者）/ admin |
| DELETE | `/api/templates/{id}` | 删除草稿 | 登录（作者） |
| POST | `/api/templates/{id}/preview` | 沙箱渲染预览（R8-A2 引擎） | 登录（作者） |

- 强制 `owner_user_id = 当前用户` 过滤（数据隔离红线，防 IDOR）。
- `PUT` 走 `version` 乐观锁，冲突返回 `409`。
- `schema` 落库前做 Schema 校验：白名单组件类型、路径、样式键；拒绝脚本 / 外链 / 危险样式（见 R8-A2）。

## 5. 前端改动

- 新增 `TemplateBuilderPage`（路由 `/templates/builder` / `/templates/builder/:id`）：
  - 组件面板（可拖拽组件列表）、画布（拖拽/排序/选中）、属性面板（绑定路径、样式表单）。
  - 拖拽库建议 `dnd-kit`；画布渲染复用 R8-A2 的 `SchemaRenderer`。
- `api/templates.ts` 新增 `createTemplate` / `updateTemplate` / `getTemplate` / `deleteTemplate` / `previewTemplate`。
- 编辑器 `Toolbar` 或主页新增「新建自定义模板」入口。
- 预览区使用沙箱 iframe（`sandbox` 属性），隔离编辑器脚本与模板脚本。

## 6. 验收标准

- 用户可不写代码拖拽生成自定义模板，保存后 `template.schema` 通过校验且 `type=user`、`owner_user_id` 正确。
- `PUT` 并发更新时乐观锁生效，旧版本返回 `409`。
- 预览效果与最终导出（R8-A2）一致；恶意 schema（脚本 / 外链 / 越界路径）被拒绝。
- 用户仅能编辑自己的自定义模板，跨用户访问返回 `404/403`。

## 7. 难点与风险

- **拖拽交互复杂度**：栅格布局、嵌套容器、对齐吸附、撤销/重做（首版可限定组件集与布局深度，避免范围蔓延）。
- **字段绑定路径合法性**：`bind` 必须是 `ResumeDTO` 白名单路径；绑定失效（字段被改）需优雅降级（空值占位），而非渲染崩溃。
- **Schema 版本演进**：`schema_version` + 迁移策略保证旧模板向前兼容（渲染引擎按版本分派渲染器）。
- **内容安全**：Schema 本质是「数据驱动的 UI」，必须与 R8-A2 的沙箱/白名单强耦合，防止存储型 XSS。
- **范围控制**：首版只支持有限组件集与两层布局，复杂交互（自由布局 / 动画）后置。
