# R8-E 简历水印防爬（可视水印 + 盲水印溯源）

> 来源：`requirements.md` §4（R8 候选 E）
> 阶段：阶段四 | 难度：⭐⭐⭐ 中 | 依赖：R8-A2 渲染引擎（导出 / 预览统一），R1 分享、R3 社区

## 1. 定位

为简历的「查看 / 导出」增加反爬与溯源手段：**可视明水印**（用户可感知，威慑截屏转发）+ **盲水印**（肉眼不可见，遭转发 / 盗用时取证溯源到具体账号）。服务于分享页、社区详情、导出图片 / PDF。

## 2. 功能点

1. **可视水印**：导出图片 / PDF 与公开查看页叠加半透明水印（访客标识：`user_id/token` 尾部、时间 / 域名），可配置密度、角度、透明度、位置。
2. **盲水印**：在导出图片 / PDF 中嵌入不可见水印（频域 / 像素级 / 文本微扰动），记录访问者信息（`user_id` 或匿名 `device_id`），支持事后解码溯源。
3. **水印策略**：登录用户导出自带（区分作者 / 访客）；匿名访客查看分享页 / 社区详情强制加访客水印；作者本人导出可选关闭。
4. **溯源工具**（管理端）：上传疑似盗用图片 → 解码盲水印 → 定位来源账号 / 设备 / 时间。
5. **可开关**：`resume.watermark.enabled`，支持按场景（导出 / 查看）独立开关。

## 3. 数据模型与配置

无新增业务表（盲水印信息直接编码在图片中，不额外落库）；新增 yml：

```yaml
resume:
  watermark:
    enabled: false
    visible:
      text: "{user}_{date}"        # 占位符替换
      opacity: 0.08
      density: medium              # light/medium/heavy
    blind:
      enabled: false
      payload: user_id|device_id   # 编码进图的信息
```

## 4. 接口（管理端溯源）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/admin/watermark/decode` | 上传疑似图片 → 解码盲水印 → 返回来源账号 / 设备 / 时间 | ADMIN |

- 导出接口 `GET /api/resumes/{id}/export`（R8-A2 统一导出）在渲染后、落地前叠加水印。

## 5. 前端改动

- 导出链路（R8-A2）渲染后叠加可视水印层；盲水印在图片生成时注入（前端或后端，视实现）。
- 分享 / 社区查看页叠加访客可视水印（CSS 蒙层或 canvas）。
- 管理端新增「水印溯源」页（上传 + 展示解码结果）。

## 6. 验收标准

- 导出图片 / PDF 含可配置的可视水印，密度 / 透明度生效；作者本人可按策略关闭。
- 匿名访客查看分享 / 社区页时叠加访客水印，且不泄露联系方式。
- 上传被盗图片可解码盲水印，定位到来源账号 / 设备 / 时间，普通压缩 / 缩放仍可解码。

## 7. 难点与风险

- **盲水印鲁棒性**：截图、转码、缩放、裁剪会破坏脆弱水印，需选用鲁棒性算法（如频域叠加），权衡不可见性与抗攻击性。
- **溯源合规**：记录访问者信息用于溯源需符合个人信息保护，仅编码最小必要标识（id + 时间），不编码姓名等。
- **性能**：图片水印计算（尤其高频 / 大图）需缓存与异步，避免拖慢导出。
- **价值有限**：水印主要起威慑，无法阻止所有盗用；建议作为安全补充项按需启动，不替代版权与法律手段。
