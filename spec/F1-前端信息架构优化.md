# F1 前端信息架构优化（导航聚合与功能分组）

> 阶段：体验优化 | 难度：⭐⭐⭐ 中 | 依赖：无（纯前端）| 范围：用户端 `src/`
> 关联：R1 分享、R2/R9 数据、R3 社区、R4/R8-A 模板、R5/R6/R8-B AI、R8-C 历史

## 1. 定位

当前用户端功能已覆盖「简历编辑 / 分享 / 模板 / 社区 / AI / 数据」，但**导航按需求（R 编号）迭代，功能入口零散平铺**：首页 header 横排 8 个同级按钮、编辑器 Toolbar 12 个按钮无分组、同一主题的功能散落多页，且存在**导航孤岛**（「我的模板」无首页入口）。

本 spec 目标：**按「用户心智」重组信息架构**，把联系紧密的功能聚合为「分区 + 二级 Tab」，统一导航与页头规范，让每个功能有清晰、可达、不重复的入口。

> 原则：只重构「信息架构 / 导航 / 页头」，不改业务逻辑与接口；旧路径保留重定向，避免书签失效。

## 2. 现状盘点

### 2.1 路由清单（13 条）

| 路由 | 页面 | 主题归属 |
|------|------|----------|
| `/login` | LoginPage | 认证 |
| `/` | ResumeListPage（个人主页，Tab：我的简历 / 我的分享） | 我的简历 |
| `/editor/:id` | EditorPage | 我的简历 |
| `/s/:key` | ShareViewPage（匿名） | 分享 |
| `/community` | CommunityPage | 他人/社区 |
| `/community/:id` | CommunityDetailPage | 他人/社区 |
| `/interview` | InterviewPage | AI |
| `/ai/history` | AiHistoryPage | AI |
| `/stats/my` | MyStatsPage | 我的数据 |
| `/templates/my` | MyTemplatesPage | 模板 |
| `/templates/builder`、`/templates/builder/:id` | TemplateBuilderPage | 模板 |
| `/templates/market` | TemplateMarketPage | 模板 |

### 2.2 入口分布（现状导航图）

**首页 header（8 项平铺，无分组）**
```
[Logo] 简历生成器 …… 用户名 | 面试准备 | AI 记录 | 数据中心 | 社区 | 模板市场 | 个人信息 | 退出登录
```

**编辑器 Toolbar（12 项平铺，无分组）**
```
返回主页 | 模板 | 配色 | AI 建议 | AI 评分 | 历史 | 分享 | 导入 | 保存 | 重置 | 导出图片 | 导出 PDF
```

**其它入口（次级/孤岛）**
- `/templates/my`（我的模板）：**首页无入口**，仅能从「模板市场」页头或模板编辑器返回到达 → **导航孤岛**
- `/templates/builder`：仅能从「我的模板」进入
- `/ai/history`、`/stats/my`：仅首页 header 有入口

### 2.3 功能主题散布（同一主题跨多页）

| 主题 | 散落位置 |
|------|----------|
| **AI** | 编辑器（AI 建议、AI 评分）、首页 header（AI 记录、面试准备） |
| **模板** | 首页 header（模板市场）、模板市场页头（我的模板）、我的模板页头（新建模板/市场）、编辑器（模板切换） |
| **个人数据** | 首页页内 Tab（我的简历、我的分享）、首页 header（数据中心）、个人信息弹窗 |
| **分享** | 首页页内 Tab（我的分享）、编辑器 Toolbar（分享） |

## 3. 问题诊断

1. **平铺无分组**：首页 8 个、Toolbar 12 个同级入口，缺少层级，用户需逐个试读才能定位功能。
2. **导航孤岛**：「我的模板」入口缺失，用户几乎无法发现（须先到市场，再点页头）。
3. **主题割裂**：AI 的 4 个入口分散在 2 个页面；模板的 3 个页面入口互不联通；「我的数据」被拆到页内 Tab + 独立页 + 弹窗三处。
4. **页头不统一**：`ResumeListPage` 无返回、`MyTemplatesPage`/`TemplateMarketPage`/`InterviewPage` 各自实现页头，样式与位置不一致。
5. **角色混淆**：首页 header 同时承载「内容入口（面试/社区/市场）」与「账户操作（个人信息/退出）」，无视觉区隔。
6. **响应式差**：header 与 Toolbar 横排按钮多，窄屏溢出。

## 4. 目标信息架构

### 4.1 一级分区（4 个）+ 二级 Tab

```
简历生成器
├─ 工作台  /                      ← 我的作品（简历 / 分享 / 模板）
│   ├─ 我的简历      (默认)
│   ├─ 我的分享
│   └─ 我的模板
├─ AI 助手 /ai                    ← 全部 AI 能力与产出
│   ├─ 面试准备      (默认)
│   └─ 生成记录
├─ 发现    /discover              ← 内容与资源
│   ├─ 社区          (默认)
│   └─ 模板市场
└─ 我的    /me                    ← 账号与数据
    ├─ 数据中心      (默认)
    └─ 个人信息
```

### 4.2 主题 → 入口 映射（消除散布）

| 主题 | 原入口 | 新入口 |
|------|--------|--------|
| 我的简历 | `/` Tab | 工作台 · 我的简历 |
| 我的分享 | `/` Tab | 工作台 · 我的分享 |
| 我的模板 | 孤岛 `/templates/my` | **工作台 · 我的模板** |
| 模板新建/编辑 | 我的模板页头 | 工作台 · 我的模板 → 新建/编辑 |
| 模板市场 | 首页 header | 发现 · 模板市场 |
| 社区 | 首页 header | 发现 · 社区 |
| 面试准备 | 首页 header | AI 助手 · 面试准备 |
| AI 记录（含评分等全部 AI 产出） | 首页 header | AI 助手 · 生成记录 |
| 数据中心 | 首页 header | 我的 · 数据中心 |
| 个人信息 | 首页 header 弹窗 | **我的 · 个人信息**（Tab，保留弹窗快捷入口） |
| AI 建议 / AI 评分 | 编辑器 Toolbar（平铺） | 编辑器 Toolbar **「AI」下拉** |
| 历史版本 | 编辑器 Toolbar | 编辑器 Toolbar 中部（保留） |
| 分享 | 编辑器 Toolbar | 编辑器 Toolbar 中部（保留） |
| 导入/保存/重置 | 编辑器 Toolbar（平铺） | 编辑器 Toolbar **「文件」下拉** |
| 导出图片/PDF | 编辑器 Toolbar（平铺） | 编辑器 Toolbar **「导出」下拉** |

### 4.3 独立子页（从列表进入，不高频直连）

- `/community/:id` 社区详情（返回社区）
- 模板市场详情 / 预览（市场内弹窗，维持现状）
- `/templates/builder(/:id)` 模板编辑器（从工作台「我的模板」进入）
- `/s/:key` 分享只读页（匿名，保持独立无壳）

## 5. 路由调整

| 新路由 | 页面 | 由旧路由重定向 |
|--------|------|----------------|
| `/` | 工作台（Tab：`?tab=resumes\|shares\|templates`） | 旧 `/` |
| `/me` | 我的（Tab：`?tab=stats\|profile`） | 旧 `/stats/my` |
| `/ai` | AI 助手（Tab：`?tab=interview\|history`） | 旧 `/interview`、`/ai/history` |
| `/discover` | 发现（Tab：`?tab=community\|market`） | 旧 `/community`、`/templates/market` |
| `/templates/my` | → 重定向 `/` + `?tab=templates` | 保留兼容 |

- Tab 用查询参数表示（`?tab=`），**可分享、可前进后退、刷新保持**；不使用纯本地 state。
- 旧路由以 `<Navigate replace>` 重定向到新路由（+ 对应 tab），保证既有书签不 404。

## 6. 关键改造

### 6.1 AppShell（新增，统一外壳）

新增 `components/layout/AppShell.tsx`：所有登录态页面共用。
- **顶部**：Logo + 一级导航（工作台 / AI 助手 / 发现 / 我的）+ 右侧账户区（用户名 · 退出）。
- **响应式**：窄屏一级导航收起为下拉/抽屉。
- **内容区**：`<Outlet />` 或 children；页面级 Tab 由各页渲染。
- 统一 current 高亮（按路径前缀匹配）。
- 编辑器 `/editor/:id` 与分享页 `/s/:key` **不套 AppShell**（全屏专注模式）。

### 6.2 页面聚合（原页内容复用，仅改容器）

| 新页面 | 组成 |
|--------|------|
| `pages/WorkbenchPage.tsx` | Tab 复用现有「我的简历」列表 + 「我的分享」列表 + 「我的模板」列表（原 `MyTemplatesPage` 内容抽为 `MyTemplateList` 组件） |
| `pages/AiHubPage.tsx` | Tab 复用 `InterviewPage` 内容 + `AiHistoryPage` 内容 |
| `pages/DiscoverPage.tsx` | Tab 复用 `CommunityPage` 内容 + `TemplateMarketPage` 内容 |
| `pages/MePage.tsx` | Tab 复用 `MyStatsPage` 内容 + `ProfileModal` 表单抽为 `ProfileForm` 组件内联 |

> 原页面组件**内容不改**，仅把「页面壳（header）」替换为 AppShell，页头级 Tab 改为查询参数驱动。

### 6.3 编辑器 Toolbar 分组

将 12 个平铺按钮重构为「**左侧文档区 / 中部结构区 / 右侧操作区**」：

```
[← 返回]  文档名                [模板 ▾] [配色 ▾] [历史] [分享]   [AI ▾]  [文件 ▾]  [导出 ▾]
```
- **AI ▾**：AI 建议、AI 评分
- **文件 ▾**：导入 JSON、保存 JSON、重置
- **导出 ▾**：导出图片、导出 PDF
- 下拉用统一的 `DropdownMenu` 组件；主操作（导出）保留高亮按钮位。

### 6.4 页头规范（统一）

- 登录态页面：由 AppShell 提供统一页头，页面不再自绘 header（移除各页 `← 返回主页` 的重复实现）。
- 匿名页（`/s/:key`、`/login`）：保持独立页头。
- 详情页（`/community/:id`）：返回按钮 + 面包屑（社区 / 详情）。

## 8. 验收标准

1. **无孤岛**：`/templates/my` 的功能在「工作台 · 我的模板」可直达；从首页出发，任意功能 ≤ 2 次点击可达。
2. **主题聚合**：AI 相关全部入口集中在「AI 助手」；模板相关全部入口集中在「工作台 · 我的模板」+「发现 · 模板市场」；个人数据集中在「我的」。
3. **入口收敛**：首页一级导航 ≤ 4 项 + 账户区；编辑器 Toolbar 可见按钮 ≤ 7 个（其余收进下拉）。
4. **路由兼容**：访问旧路径（`/interview`、`/ai/history`、`/stats/my`、`/templates/market`、`/community`、`/templates/my`）均重定向到新路径且落到正确 Tab。
5. **Tab 可分享**：Tab 状态体现在 URL（`?tab=`），刷新/复制链接/前进后退行为正确。
6. **响应式**：窄屏（≤768px）一级导航收起为抽屉，无横向溢出。
7. **零业务回归**：接口调用、数据隔离、乐观锁、导出等逻辑不变；`npm run build` 通过。

## 9. 实施顺序（可分步上线，每步可独立验收）

1. **Page 骨架**：新增 `AppShell` + `NavTabs` + 4 个聚合页骨架，路由改造 + 旧路由重定向（页面内容先原样嵌入）。
   → 验收：旧路径可达、新路径可用、无功能丢失。
2. **工作台聚合**：把「我的模板」并入工作台（消除孤岛）。
   → 验收：标准 1、2 达成。
3. **AI / 发现 / 我的 聚合**：三页 Tab 化。
   → 验收：标准 2、5 达成。
4. **Toolbar 分组**：编辑器 12 按钮收敛为分组 + 下拉。
   → 验收：标准 3 达成。
5. **页头统一与响应式**：移除各页自绘 header，接入 AppShell 响应式。
   → 验收：标准 4、6、7 达成。

## 10. 风险与注意

- **回归风险**：本次为「容器/导航重构」，需逐页对照原功能清单核验（尤其分享 Tab、模板状态标签、AI 记录详情弹窗）。
- **Tab 与路由的耦合**：Tab 用查询参数而非 state，注意与 `RouteTracker` 埋点（`app.tsx` 里按 `pathname` 上报）的兼容——埋点应继续按一级路径上报，不要因 `?tab=` 变化重复计数。
- **AI 记录筛选**：`AiHistoryPage` 原按 `taskType` 筛选（题库/改稿/润色/扩写/建议/评分），并入「AI 助手 · 生成记录」后筛选器保留。
- **编辑器专注模式**：编辑器不套 AppShell，需保证「返回工作台」入口仍在，不因去掉 header 而丢失导航。
- **权限/匿名**：`/discover` 的社区与市场为匿名可访问；`/me`、`/ai`、工作台需登录（沿用 `RequireAuth`）。匿名访问 `/discover` 时账户区显示「登录」而非用户名。
- **不引入新依赖**：下拉/抽屉/响应式用现有 Tailwind + 轻量自研组件实现，不引入 UI 库（保持纯 HTML/CSS/JS 风格）。
