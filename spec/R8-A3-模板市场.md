# R8-A3 模板市场（发布 / 审核 / 搜索 / 一键用）

> 来源：`requirements.md` §4（R8 候选 A 拆分）
> 阶段：阶段四 | 难度：⭐⭐⭐ 中 | 依赖：R8-A1 可视化编辑器、R8-A2 渲染引擎、R4 模板表、社区规则引擎（R3，可复用审核）

## 1. 定位

把 R8-A1 产出的用户自定义模板变成**可发现、可复用、可治理**的模板市场，形成生态与壁垒。用户提交模板上架 → 审核 → 公开列表被搜索 / 预览 → 其他用户「一键用」应用到自己的简历。

## 2. 功能点

1. **发布 / 审核**：用户模板 `draft → pending` 提交审核；管理端审核通过 → `online`，拒绝 → 回退草稿并给出原因。
2. **市场列表**：公开浏览 `online` 模板，支持分类 / 风格筛选、热度 / 最新排序、关键词搜索、分页。
3. **一键用**：登录用户「使用」某模板 → 复制应用到自己的某份简历（写 `resume.template_id = template.code`）。
4. **详情 / 预览**：缩略图、R8-A2 沙箱预览、作者信息、使用次数、浏览数。
5. **治理**：管理端审核、上下架、删除；举报与敏感词检测（复用 R3 `AuditRuleEngine`）。
6. **计数**：模板使用数 / 浏览数（读模型计数 + 明细事实，可复用 R3-A 写扩散思路）。

## 3. 数据模型

复用 R4 / R8-A1 的 `template` 表，扩展状态与计数：

```sql
-- template 已有：code/name/type/category/schema/thumbnail/sort_order/status/created_at/updated_at
-- R8-A1 新增：owner_user_id / version / schema_version
-- R8-A3 状态位语义扩展：status 0下架 1上架(=online) 2待审(pending) 3草稿(draft)（官方模板恒为 1）

ALTER TABLE template ADD COLUMN use_count  BIGINT NOT NULL DEFAULT 0 COMMENT '被使用次数' AFTER version;
ALTER TABLE template ADD COLUMN view_count BIGINT NOT NULL DEFAULT 0 COMMENT '浏览数' AFTER use_count;
ALTER TABLE template ADD COLUMN published_at DATETIME DEFAULT NULL COMMENT '上架时间' AFTER status;
ALTER TABLE template ADD KEY idx_status_time (status, published_at);
```

> 说明：若希望审核状态与「上下架」解耦，可引入独立 `template_audit` 明细表；首版建议复用 `status` 多态 + `audit_reason` 字段（`ALTER TABLE template ADD COLUMN audit_reason VARCHAR(255)`）。

## 4. 接口

| 方法 | 路径 | 说明 | 鉴权 |
|------|------|------|------|
| POST | `/api/templates/{id}/publish` | 提交上架（draft→pending） | 登录（作者） |
| GET | `/api/templates/market` | 市场列表（搜索/筛选/分页，仅 online） | 匿名可 |
| GET | `/api/templates/market/{id}` | 市场详情（含预览） | 匿名可 |
| POST | `/api/templates/{id}/use` | 一键使用（绑定到某简历） | 登录 |
| 管理端 | `PATCH /admin/templates/{id}/audit` | 审核通过 / 拒绝 / 上下架 | ADMIN |
| 管理端 | `GET /admin/templates?status=all` | 全部模板（含待审） | ADMIN |

- 市场列表 / 详情匿名可访问（与 `/community` 一致），但「一键用」「发布」需登录。
- 「一键用」校验目标简历归属（强制 `user_id` 过滤）；`use_count` 走计数写扩散 / 乐观锁聚合。

## 5. 前端改动

- 新增 `TemplateMarketPage`（列表 / 筛选 / 搜索 / 分页）+ `TemplateDetailModal`（预览 + 一键用）。
- 编辑器「发布到市场」「我的模板」入口；`App.tsx` 增路由 `/templates/market`。
- `api/templates.ts` 新增 `listMarketTemplates` / `getMarketTemplate` / `useTemplate` / `publishTemplate`。
- 管理端（admin-ui）新增「模板审核」页：待审列表、通过 / 拒绝 / 上下架。

## 6. 验收标准

- 用户模板可「发布 → 审核 → 上架」，上架后匿名可搜索并预览。
- 登录用户可「一键用」模板到自己的简历，`use_count` 正确累加；跨用户 / 未授权操作被拒绝。
- 管理端可审核（通过 / 拒绝 / 上下架 / 删除），敏感词 / 违规模板被拦截。
- 模板搜索 / 筛选 / 排序 / 分页正确，审核未通过的模板不出现在市场。

## 7. 难点与风险

- **内容审核**：模板既含文本（名称 / 摘要）也含可视化结构（易藏诱导 / 侵权），审核以文本 + 缩略图人工抽检为主，规则引擎兜底。
- **计数一致性**：`use_count` / `view_count` 高并发写入，复用 R3-A「读模型 + 事实模型」写扩散，保证最终一致。
- **市场冷启动**：以三套官方内置模板 + 精选模板打底，避免空市场。
- **版权**：用户模板的原创性审核与侵权申诉通道（合规），见 `requirements.md` §8「模板市场版权」决策点。
- **渲染安全**：市场预览必须复用 R8-A2 沙箱渲染，防恶意模板在公开页执行脚本。
