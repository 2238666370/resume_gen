# R8-A4 自由画布模板设计器（Canvas 绘制式）

> 阶段：能力升级 | 难度：⭐⭐⭐⭐⭐ 高 | 依赖：R8-A1（可视化编辑器）、R8-A2（Schema 安全）、R8-A3（模板市场）
> 范围：用户端 `src/`（编辑器 + 渲染器 + 导出链路） + 后端 `SchemaValidator` / `template` 表
> 关联：R4 模板数据化、R8-A1/A2/A3、F1 信息架构

## 1. 定位

把模板编辑从「**选板块 + 换主题预设**」升级为「**在 A4 画布上自由绘制**」：用户可以任意摆放文本框、头像、形状、分割线，并把元素绑定到简历数据，像 Canva / Figma 一样所见即所得地设计简历模板。

**目标**：模板形态不再被「头部 + 流式板块」写死，用户可做出侧边栏式、时间轴式、杂志排版式等任意版式。

## 2. 现状与差距

| 维度 | 现状（R8-A1） | 目标（R8-A4） |
|------|---------------|---------------|
| 结构 | `sections[]` 固定顺序，只能在 1/2 栏间拖拽 | 元素绝对定位（x/y/w/h），任意摆放与层级 |
| 样式 | 4 种标题纹饰 + 2 种板块样式 + 2 种头部对齐 | 逐元素字号/字重/颜色/行高/对齐/圆角/边框/背景 |
| 元素 | 仅预定义板块（工作经历…） | 文本、单值字段、列表、图片、形状、分割线、标题 |
| 数据 | 板块类型隐式绑定 | 显式路径绑定（`personal.name`、`experience[].company`） |
| 版式 | 单栏/双栏 | 任意分栏、侧边栏、自由网格 |
| 分页 | 无（内容超长只溢出） | 溢出检测 + 自动分页 |

**根因**：`TemplateSchema` 是「配置型」模型（[schema.ts](file:///d:/code/resume_gen/src/types/schema.ts#L37-L43)），渲染路径写死在 [CustomSchemaTemplate.tsx](file:///d:/code/resume_gen/src/components/templates/CustomSchemaTemplate.tsx#L26-L34)。要提升自由度，必须换模型。

## 3. 核心设计

### 3.1 数据模型：Schema v2（画布）

新增 `layout: 'canvas'`，与既有 `classic/modern/minimal/custom` 并存（**双渲染器**，旧模板零影响）。

```ts
interface CanvasSchema {
  schemaVersion: 2;
  layout: 'canvas';
  page: { width: 210; height: 297; unit: 'mm'; margin: { top; right; bottom; left } };
  theme: { fontFamily: string; baseFontSize: number; palette: { primary; text; muted; line } };
  elements: CanvasElement[];        // 扁平数组，靠 zIndex 定层级
}

interface ElementBase {
  id: string;
  name?: string;                    // 图层名
  x: number; y: number;             // mm，相对页面左上
  w: number; h: number;             // 设计时尺寸（mm）
  zIndex: number;
  locked?: boolean;
  hidden?: boolean;
  style: ElementStyle;
}

type CanvasElement =
  | ({ type: 'text' } & ElementBase & { value: string })                       // 静态文本
  | ({ type: 'field' } & ElementBase & { bind: Bind; prefix?; suffix? })       // 单值字段
  | ({ type: 'heading' } & ElementBase & { value: string; decoration })        // 板块标题
  | ({ type: 'list' } & ElementBase & { bind: Bind; itemGap; divider; maxPerPage?; itemTemplate: ElementBase[] })
  | ({ type: 'image' } & ElementBase & { source: 'avatar' | 'url'; url?; fit; radius })
  | ({ type: 'shape' } & ElementBase & { shape: 'rect' | 'ellipse' | 'line'; fill; stroke })
  | ({ type: 'group' } & ElementBase & { children: CanvasChild[] });           // 成组：children 用组内相对坐标

interface Bind { path: string; fallback?: string }   // path 走白名单，如 'personal.name'

interface ElementStyle {
  fontFamily?: string; fontSize?: number;   // pt（排版习惯）；坐标仍用 mm
  fontWeight?: number; italic?: boolean;
  color?: string; lineHeight?: number; letterSpacing?: number;
  textAlign?: 'left' | 'center' | 'right';
  verticalAlign?: 'top' | 'middle' | 'bottom';
  padding?: number; background?: string; opacity?: number;
  border?: { width: number; color: string; radius: number };
}
```

**为什么扁平 + zIndex**：绘制顺序与命中检测、图层排序、撤销重做都更简单；`list` 的 `itemTemplate` 是唯一嵌套（层级 ≤ 2）。

### 3.2 布局引擎：锚点流式（Anchor Flow）

**这是本方案最关键的技术点**。画布要求绝对定位，但简历内容是**变长的**（工作经历可能 2 条也可能 8 条）。纯绝对定位会导致列表变长时压住下方元素。

解决思路：**设计时高度 ≠ 运行时高度，按「列（lane）」自顶向下推挤补偿**。

```
1. 分列（lane）：把元素按水平投影重叠聚类（x 区间相交 → 同一 lane）。
2. 逐 lane 自顶向下遍历：
     actualH = 流式元素按内容实测高度（list/text 换行后），普通元素 = 设计高 h
     delta   = actualH - h
     若 delta > 0：该 lane 中 designY ≥ 本元素底边的元素，统一 y += delta
3. 迭代至收敛（最多 3 轮，避免相邻元素互相推挤震荡）。
4. 溢出检测：任一元素底边 > page.height - margin.bottom → 标记溢出。
```

效果：用户在设计态看到的是**设计稿**（固定高度占位），运行态自动按真实内容下推；同一列内元素保持相对关系，不同列互不干扰。

**分页（手动）**：`pageBreak` 元素按 `y` 升序把画布切成 N 段，**每页独立做锚点流式布局**；元素坐标换算为「页内坐标」（减去该页 `top`），因此某一页的列表变长**不会影响其他页**。边界规则：`y` 恰好落在分页符上的元素归入下一页；连续分页符产生的空页被跳过。设计态把分页符渲染为标记线（提示「第 N 页从这里开始」），运行态渲染为多张 A4 页面。不做自动分页——内容超长仍由溢出提示暴露。

### 3.3 渲染器：编辑器与成品共用一套

新增 `CanvasTemplateRenderer`，**编辑器画布、模板市场缩略图、简历预览、PNG/PDF 导出、分享页** 全部复用它（只读 props：`data + schema`）。

- 编辑器在其上叠加一层**交互层**（选中框、8 向缩放手柄、对齐参考线、网格），不改渲染 DOM。
- 单位统一 mm，`1mm ≈ 3.7795px`；缩放仅用 CSS `transform: scale()`，导出时按真实尺寸渲染 → **所见即所得**。
- 导出沿用现有 [export.ts](file:///d:/code/resume_gen/src/utils/export.ts)（html2canvas / 打印），指向同一 DOM 节点，无需改导出逻辑。

### 3.4 编辑器交互

**三栏布局**：左「组件库 + 图层」· 中「画布」· 右「属性面板」。

| 能力 | 说明 |
|------|------|
| 组件库 | 文本 / 数据字段 / 列表 / 标题 / 图片 / 形状 / 分割线；另设**区块预设**（头部、时间轴条目、技能条）一键落版 |
| 画布 | 缩放（50%~200%）、平移、标尺、网格、A4 边界与安全区、出血提示 |
| 元素操作 | 拖拽移动、8 向缩放、方向键微调（Shift 加速）、框选/Shift 多选 |
| 对齐辅助 | 元素间吸附（阈值 2px）、页面居中/边缘吸附、等距参考线 |
| 批量 | 对齐（左/中/右/顶/中/底）、分布、等宽等高、成组 / 解组（Ctrl+G / Ctrl+Shift+G） |
| 图层 | 元素树、重命名、显隐、锁定、拖拽调层级、置顶/置底 |
| 属性面板 | 位置尺寸、样式、**数据绑定**（下拉选字段 + 兜底文案）、列表配置（数据源/间距/分隔线/每页条数） |
| 撤销重做 | 快照栈（schema 体积可控，上限 50 步） |
| 快捷键 | Ctrl+C/V/D 复制粘贴、Ctrl+Z/Y 撤销重做、Delete 删除、方向键微调、Ctrl+S 保存 |
| 数据预览 | 切换「示例数据 / 我的简历」，实时看到真实内容下的推挤与溢出效果 |

### 3.5 数据绑定

- 单值：`bind.path` 从下拉选择，路径白名单见下。
- 列表：`bind.path` 指向数组，`itemTemplate` 内元素的坐标是**相对条目框**的局部坐标；条目高度按内容实测后累加。
- 富文本：文本值支持 `**加粗**`，复用现有 [textRenderer.tsx](file:///d:/code/resume_gen/src/utils/textRenderer.tsx)（内部已做 HTML 转义）。

**路径白名单**（前后端共用同一份定义）：

```
personal.{name,title,email,phone,location,website,avatar,summary}
education[].{school,degree,major,startDate,endDate,gpa,description}
experience[] / internship[].{company,position,startDate,endDate,current,description}
skills[].{name,level}
projects[].{name,role,startDate,endDate,description,link}
certificates[].{name,issuer,date,link}
languages[].{name,level}
customSections[].{title,content}
```

### 3.6 后端：校验扩展

`SchemaValidator` 已具备白名单 + XSS + 危险样式拦截（[SchemaValidator.java](file:///d:/code/resume_gen/resume-server/src/main/java/com/resumegen/service/SchemaValidator.java#L26-L42)），扩展即可：

| 项 | 现状 | 改为 |
|----|------|------|
| `LAYOUTS` | classic/modern/minimal/custom | 增加 `canvas` |
| 元素类型 | 仅校验 `sections` | 新增 `elements[].type` 白名单 |
| 绑定路径 | 无 | `bind.path` 必须命中路径白名单（防注入 + 防读到非预期字段） |
| 数值范围 | 无 | `x/y ≥ 0`、`x+w ≤ page.width + 10`、`fontSize ∈ [6,72] pt`、`zIndex ∈ [0,999]` |
| 颜色 | 无 | 仅 `#RGB` / `#RRGGBB` / `rgba()` / 主题变量 |
| 图片 | 无 | 仅 `source ∈ {avatar, url}`，`url` 必须是 `https?://`（**禁止本地图片 / base64**） |
| 成组 | 无 | `group.children` 递归校验，组内为相对坐标；嵌套深度 ≤ 2 |
| 规模上限 | nodes 500 / depth 6 / sections 100 | nodes **3000** / depth **8** / elements **400** |
| 危险样式 | 已禁 `expression(`/`url(`/`@import`/`position:fixed`/`behavior:` | 保留（`position:absolute` 允许） |

> 校验失败一律 400 并给出可读原因，前端定位到具体元素提示。

### 3.7 兼容与迁移

- `template.schema_version` 列已存在（默认 1），画布模板写 **2**；市场缩略图与简历预览按版本分派渲染器（v1 → `CustomSchemaTemplate`，v2 → `CanvasTemplateRenderer`）。
- **结构化编辑器（R8-A1 `TemplateBuilderPage`）移除**，模板的新建与编辑统一走画布设计器，不再保留双编辑器入口。
- 旧 v1 模板**渲染兼容保留**（市场与简历中照常显示）；用户在画布设计器中打开旧模板时，先由「结构化 → 画布」转换器转成画布初始稿，保存后升级为 v2。
- 模板市场需支持 v2 缩略图（用 `SAMPLE_RESUME` 渲染）。

### 3.8 与既有数据库表的映射

画布模板**只存布局**（`template.schema` JSON 列，`schema_version=2`），简历内容仍存于既有 `resume_*` 表，渲染时按 `bind.path` 现取 —— **不新增任何表**。

| 画布元素 | `bind.path` | 对应表 | 说明 |
|---|---|---|---|
| `field` | `personal.name/title/email/phone/location/website/avatar/summary` | `resume_personal` | 单值字段一一对应 |
| `list` | `education` | `resume_education` | 一条记录渲染一个条目 |
| `list` | `experience` / `internship` | `resume_experience` | 同表，靠 `item_type` 区分 |
| `list` | `skills` / `projects` / `certificates` / `languages` | 对应明细表 | 同上 |
| `list` | `customSections` | `resume_custom_section` | **新块一律走这里**，字段仅 `title` + `content` |
| `heading` / `text` / `shape` / `image` / `group` / `pageBreak` | 无绑定 | 不落库 | 纯排版装饰 |

- **固定块**：组件库把 7 个固定块（与明细表 1:1）做成可直接落版的入口，块内元素用 `itemTemplate` 自由摆放。
- **新块**：不在固定集合内的一律绑定 `customSections`（标题 + 正文），即写入 `resume_custom_section`。
- **显隐联动**：渲染与布局共用 `sectionVisibility`，按简历的 `resume_section` 过滤 —— 板块被隐藏时列表条目数为 0、**高度塌缩为 0**，下方元素自动上移，不留白。

## 5. 实施分期

| 阶段 | 内容 | 验收 |
|------|------|------|
| **P0** 模型与渲染 | Schema v2 类型 + 布局引擎 + `CanvasTemplateRenderer` + 后端校验扩展 | 手写一份 v2 schema 能正确渲染、推挤、导出；非法 schema 返回 400 |
| **P1** 编辑器骨架 | 画布（拖拽/缩放/网格/参考线）+ 图层 + 属性面板（位置尺寸/样式）+ 成组/解组 + 保存/加载；同时移除旧结构化编辑器 | 能画出静态版式并保存、重开还原；可成组拖拽 |
| **P2** 数据与效率 | 数据绑定（字段 + 列表）、数据预览切换、撤销重做、吸附、批量对齐、快捷键 | 绑定真实简历后自动推挤正确；Ctrl+Z 可回退 |
| **P3** 完整闭环 | 溢出提示与手动分页符、区块预设库、结构化→画布转换、模板市场混排接入、审核 | 能发布到市场并被他人在简历中套用 |

> 建议 P0+P1 先上线（可保存但功能较简），P2/P3 迭代。每阶段可独立验收。

## 6. 验收标准

1. **自由度**：能做出至少三种现有模板无法实现的版式（侧边栏、时间轴、杂志双栏错位）。
2. **所见即所得**：编辑器画面、简历预览、导出 PNG/PDF 三者视觉一致（字体/位置/尺寸）。
3. **变长内容正确**：把工作经历从 1 条改到 8 条，下方元素自动下移且不重叠；溢出时有明确提示。
4. **数据绑定**：元素绑定字段后随简历数据实时更新；列表按条目数自动展开。
5. **安全**：注入 `<script>`、`position:fixed`、`url(...)`、非法绑定路径、超限元素数的 schema 均被 400 拒绝。
6. **兼容**：存量 v1 模板在市场、简历预览、导出中行为完全不变。
7. **可回退**：画布编辑全程支持撤销/重做，保存失败不丢编辑态。
8. **性能**：200 个元素时拖拽帧率 ≥ 50fps（拖拽走 overlay transform，松手才提交 store）。

## 7. 难点与风险

| 难点 | 说明 | 对策 |
|------|------|------|
| 变长内容 vs 绝对定位 | 简历天然变长，纯画布会重叠 | 锚点流式推挤（3.2）；分列隔离；溢出提示 |
| 分页 | 推挤后可能跨页 | 本期**不做自动分页**：溢出提示 + 手动 `pageBreak` 元素，元素越界给醒目告警 |
| 编辑器与导出一致性 | mm/px 换算、字体差异、缩放 | 共用渲染器 + 导出按真实尺寸渲染；固定字体白名单 |
| 拖拽性能 | 每帧全量 re-render 卡顿 | overlay 层 transform + 松手提交；zustand 细粒度 selector |
| 移动端 | 画布交互在小屏体验差 | 明确「设计器仅桌面端可用」，小屏给只读预览与提示，不渲染编辑器 |
| Schema 膨胀 | 元素多导致 JSON 大、校验慢 | 上限 400 元素 + 3000 节点；存 JSON 列；校验 O(n) |
| 复杂度 | 相当于重做一个前端子应用 | 分期落地，P0/P1 先跑通闭环 |

## 8. 已确认决策

| # | 决策点 | 结论 | 对设计的影响 |
|---|--------|------|--------------|
| 1 | 分页 | **手动** | 本期只做溢出提示 + `pageBreak` 元素；自动分页移出范围 |
| 2 | 成组 | **支持** | 数据模型新增 `type:'group'` + `children`（组内相对坐标，嵌套 ≤ 2 层）；命中检测/拖拽/缩放按组处理；纳入 P1 |
| 3 | 本地图片 | **不允许** | `image.source` 仅 `avatar` / `url`；后端禁止 `data:image/` base64（无 OSS，避免图片入库膨胀） |
| 4 | 旧编辑器 | **不保留** | 移除 `TemplateBuilderPage` 与结构化编辑入口，统一走画布设计器；v1 仅保留渲染兼容 |
| 5 | 模板市场 | **混排** | 市场不分区，v1/v2 按 `status + sort_order` 混排；缩略图按 `schemaVersion` 分派渲染器 |
| 6 | 字号单位 | **pt** | 属性面板与 `style.fontSize` 用 pt（`1pt = 1/72in`，A4 = 595×842pt）；坐标仍用 mm（`1mm = 2.8346pt`） |
| 7 | 自定义块字段深度 | **方案 A** | `resume_custom_section` 维持 `title` + `content`，不改表结构；新块只承载标题 + 正文 |
| 8 | 板块显隐联动 | **接入** | 渲染与布局共用 `sectionVisibility`，按 `resume_section` 过滤；隐藏板块条目数 0、高度 0、下方元素上移 |
